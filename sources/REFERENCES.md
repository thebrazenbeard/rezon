# References

This file records external repositories examined during Rezon’s initial knowledge population. Inclusion is not endorsement and does not imply code reuse.

## Reasoning / state / knowledge systems

- https://github.com/basiralab/HCAE — multi-view HyperConnectome AutoEncoder; relational views, hypergraph construction, learned embeddings.
- https://github.com/sapientinc/HRM — Hierarchical Reasoning Model; high-level/low-level recurrent reasoning architecture.
- https://github.com/OpenSPG/KAG — Knowledge Augmented Generation; logical-form-guided hybrid planning/reasoning/retrieval.
- https://github.com/VectifyAI/PageIndex — hierarchical, reasoning-based retrieval without requiring vector similarity as the primary index.
- https://github.com/semantica-agi/semantica — context graphs, provenance, deterministic reasoning, conflict detection, ontology governance.
- https://github.com/ThHanke/ontosphere — RDF/OWL graph editor, OWL 2 DL reasoning, SHACL, verified repairs, canonicalization, MCP.
- https://github.com/acrion/zelph — executable semantic graph, unification, rules, derivation/proof-oriented reasoning.

## Source-use rules

1. Record the mechanism being transferred, not merely the source’s marketing category.
2. Preserve source limitations. If implementation is redacted, do not infer undocumented mechanics.
3. Separate conceptual transfer from code reuse.
4. Check licenses before copying or linking runtime code.
5. Re-evaluate external benchmarks on Rezon-relevant tasks before using them as design evidence.
6. External projects remain evidence/research; they do not automatically become Rezon authority or dependencies.
