## Portable protocol (source: `src/rezon/federation.py`)

`SharedTopic` canonicalizes the exact question and constraints. `BlindProposal` stores one literal claim, disconfirming observation, source/method/input metadata, and a 16-byte nonce. `commit()` produces the public digest/worker/host tuple.

`SharedEpisode.submit_commitment()` rejects unassigned host IDs, changed topics and duplicates. `SharedEpisode.reveal()` rejects early disclosure before every registered worker has committed, post-hoc substitutions and replay. `SharedEpisode.challenge()` requires four revealed proposals and an exact opposing target digest, preserving objection + falsification test without majority-vote truth.

**This is an in-process verifier over portable packets.** Transport is currently explicit GitHub Issue #85 / Cognition Bus #387 exchange. There is no automatic cross-host service, authenticated network RPC, external custody, worker attestation, or continuously running autonomous agent. A host may lie about its own input model or whether peers were visible; the protocol is only an honest-participant choreography and ordinary hash consistency check.
