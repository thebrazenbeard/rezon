## Replication

Install both models using `ollama pull lfm2.5-thinking:1.2b` and
`ollama pull gemma3:1b`. Set each participant's `provider` to
`openai_compatible`, `base_url` to the loopback `/v1` endpoint,
`api_key_env` to `REZON_LOCAL_OLLAMA_KEY`, and distinct `agent_id` values.
Set that variable to a nonempty placeholder (Ollama loopback does not verify it).
For this probe, `timeout_seconds=240`, `max_tokens=768`,
and `reasoning_effort="none"` for Liquid were used.
Use Gemma 3 1B as a separately configured integrator.

Run `python -m rezon.collective_cli run --db <path-to-db>
--prompt "Compare two possible explanations" --models-config <models-json>
--integrator-config <integrator-json>` with `PYTHONPATH=src` from the
repository root, or install the package first. The on-device launcher is
`C:\Users\Vera\AppData\Local\Rezon\run_local.cmd`.

Two full CLI episodes were observed in
`C:\Users\Vera\AppData\Local\Rezon\state\episodes.sqlite3`.
The database contained 2 episodes, 4 enrolled participant records, 4
independent answers, 4 peer reviews, and 2 syntheses. The counts were

generated distinct episode IDs.

The modified provider/CLI source passed **6 focused tests**, and the
entire local Rezon suite passed **354 tests, 1 skipped** (Python 3.13.15;
isolated `--basetemp` was required to avoid the host's pytest default
temporary-directory cleanup permission error).

## Limits and open issues

- Liquid returned embedded `<think>` markers in its answer/review
  content, despite an attempted `reasoning_effort="none"` setting.
- The 1B integrator generated lengthy, self-referential syntheses
  (roughly 3.8k characters each). The pipeline worked; answer
  concision and reasoning quality were **not established**.
- No remote agent rendezvous, external provider, independent factual
  verification, or measurable reasoning improvement was tested.
- This uses one local SQLite authority, not distributed consensus.

## Separately authenticated gateway smoke test

A second VN1 runtime probe used distinct random agent bearer tokens, an
independent administrator token, and an ephemeral gateway listener bound to
`127.0.0.1` on an OS-selected port. Concurrent HTTP requests from
`agent_alpha` and `agent_beta` each received 201 and populated a single
completed episode; administrator-token answer submission returned HTTP 403.
Credentials were generated in-process and not printed or retained. The
listener was shut down after this test. This qualifies loopback concurrency
and basic authorization, **not** remote access or persistent service startup.
