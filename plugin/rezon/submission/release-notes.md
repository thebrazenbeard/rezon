# Rezon 0.1.0 release notes

Initial skills-only Plugin candidate for Rezon.

This version packages three reusable reasoning workflows:

- structured multi-view analysis with explicit uncertainty and opposition;
- hostile review that preserves the literal proposition under attack;
- evidence reconciliation with provenance, currentness, independence, and effect-state controls.

No MCP server, external account, provider activation, deployment behavior, or repository Python runtime is bundled. This candidate is source-prepared but not submitted or published.
