# Evidence reconciliation contract

For each material item, capture as much of this as the evidence supports:

- source identity;
- subject/referent;
- version or observation time;
- proposition supported or contradicted;
- direct vs transformed evidence;
- upstream lineage;
- currentness for the requested claim;
- confidence or epistemic state;
- authority scope;
- effect state, if any.

Reconciliation rules:
- no-match is not exhaustive absence unless the search surface proves exhaustiveness;
- newest is not automatically most authoritative;
- repeated summaries do not create independent evidence;
- a stronger model is not an authority source by itself;
- a valid digest proves integrity only for what the digest actually binds;
- uncertainty should survive into the answer when the evidence cannot close it.
