# Rezon core contract

Rezon treats reasoning as a structured, falsifiable process rather than one monolithic answer.

Core separations:
- claim is not evidence;
- an observation is not the subject itself;
- reasoning method does not grant authority;
- reasoning quality does not prove a runtime effect;
- a representation is not the represented reality;
- ambiguity, unknown, conflicting, and verified states are materially different.

A useful run shape is:

Task or proposition -> decomposition -> heterogeneous reasoning operations -> opposition/falsification -> provenance reconciliation -> integration -> result receipt.

Reasoning nodes should be understood as constrained epistemic operations. Diversity matters when methods, inputs, or executors differ in ways relevant to the failure mode. More generated arguments are not automatically more evidence.

The final synthesis should preserve source paths and uncertainty. Unsupported consensus must not be promoted into evidence.
