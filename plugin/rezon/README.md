# Rezon Plugin

This package exposes Rezon's reusable reasoning workflows as a skills-only ChatGPT/Codex Plugin.

It does not connect to an MCP server, does not require an account or credentials, and does not claim to execute Rezon's repository Python kernel. The packaged Skills encode the repository's reasoning contracts for use by the host model.

## Skills

- `rezon-analysis` — structured multi-method reasoning with explicit uncertainty and a bounded result receipt.
- `rezon-hostile-review` — adversarially test a literal proposition, plan, or conclusion without consensus laundering.
- `rezon-evidence-reconciliation` — reconcile conflicting or versioned evidence with provenance, currentness, and independence controls.
